# Maria - Portfolio Website

A modern, responsive portfolio website for a digital designer, built with React and Tailwind CSS.

## Features

- Responsive design that works across devices
- Multiple page layout with React Router
- Portfolio project showcase with filtering
- Detailed project pages
- About page with professional information
- Modern animations and transitions

## Technologies Used

- React 18
- Tailwind CSS
- React Router
- TypeScript
- Vite

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/en/) (v16 or higher)
- [Bun](https://bun.sh/) (recommended) or npm

### Installation

1. Clone the repository
   ```bash
   git clone [repository-url]
   cd maria-portfolio-clone
   ```

2. Install dependencies
   ```bash
   bun install
   # or
   npm install
   ```

3. Start the development server
   ```bash
   bun run dev
   # or
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser

## Building for Production

To create a production build, run:

```bash
bun run build
# or
npm run build
```

The build files will be in the `dist` directory.

## Project Structure

- `/public` - Static assets
- `/src` - Source code
  - `/components` - UI components
    - `/layout` - Layout components (Header, Footer)
    - `/sections` - Section components for homepage
    - `/portfolio` - Portfolio-related components
  - `/pages` - Page components
  - `/data` - Data files
  - `/styles` - CSS files
